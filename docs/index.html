01 Travel & decision tools

Cost Mapping

What does a trip actually leave you?

A payout is only part of the story. Cost Mapping brings driving, waiting, vehicle expenses, and your time into the same calculation—so you can compare gigs on what you keep.

  • Trip costs, net earnings, and effective hourly pay
  • Offline estimates and optional Google Routes integration
  • Geographic cost surfaces, comparisons, and exports

Python · Local web app · CLI

02 Media & command-line tools

stream.sh

A media library, ready to go live.

A Bash companion for FFmpeg that handles the parts between choosing a file and getting it on a stream. Built for local media, with useful defaults and explicit controls when you need them.

  • File discovery, playlists, shuffle, and looping
  • Encoding profiles, audio controls, and live RTMP output
  • Bounded retries and clean cancellation on macOS and Linux

Bash · FFmpeg · RTMP

03 Tabletop games & creative tools

Bastion
Character Workshop

Less setup. More time at the table.

An unofficial Electric Bastionland character generator that turns a handful of dice rolls into the start of an adventurer. Make a character or a whole crew, then keep the details in a format that fits your game.

  • Seeded characters, parties, and custom career packs
  • A local browser workshop and printable character sheets
  • JSON, CSV, Markdown, and HTML exports

Python · Reproducible generation · Local web app

About the work

A question.
A useful little tool.

These projects started with distinct questions: how to see the real cost of travel, how to make a media stream dependable, and how to get a character ready for a game.

The common thread is software you can run yourself, with clear inputs, inspectable results, and source code you can change. Some of it is practical. Some of it is for play.
